entityraster#

Raster-valued attributes for GeoPandas. Keep one raster per row (a person’s activity space, a site’s suitability surface, a parcel’s land-cover map) as an ordinary column of a (Geo)DataFrame, and ask questions of it the way you already ask questions of tables: filter it, group it, join it, save it. We call such a table a GeoRasterFrame.

import entityraster as er

gdf = er.embed(people, "rasters/", on="uid", pattern="p{uid:05d}.tif", column="activity_space", index="uid")

gdf.loc[200, "activity_space"].mean()                                   # one person's raster
gdf["area_km2"] = gdf["activity_space"].raster.area(0.5, relative=True) / 1e6   # one value per person
old = gdf[gdf["age"] > 60]                                              # rasters follow the filter
old.rst.surface("activity_space", by="gender", outside="unknown")       # a mean surface per group

FAQ and troubleshooting

Why a raster column?#

The usual way to work with one raster per person is a path column and a hand-written loop that opens each file, aligns arrays, accumulates results in dictionaries and merges them back. That is long, and it is where silent errors hide (rasters with different origins stacked as if they were aligned; cells outside a raster treated as zero or as missing without anyone deciding). entityraster keeps the reference to each raster, with its metadata, in the table, reads pixels only when needed, refuses to guess when rasters do not line up, and makes you state whether cells outside a raster mean zero or unknown.
