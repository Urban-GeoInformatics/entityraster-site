Glossary#

GeoRasterFrame#

A (Geo)DataFrame in which one column holds one raster per row. A data structure, not a file format and not a new class: a table is a GeoRasterFrame if it has a column of dtype raster. Check with entityraster.is_georasterframe().

entity#

What a row describes: a person, a parcel, a site. The raster is an attribute of the entity.

reference (RasterRef)#

What the raster column actually stores for each row: the file path, band, and cached metadata. Pixels are read only on demand.

extent#

The rectangle a raster covers (its bounding box), or, with extent="valid" / "hull", the outline or convex hull of the cells that have a value.

footprint#

The bounding box of a raster as a polygon.

nodata#

Cells that have no value. Statistics for a single raster ignore them by default.

outside (zero vs unknown)#

What a cell outside an entity’s raster (or a nodata cell) means when rasters of several entities are combined. "zero": the entity was never there, the cell counts as 0 and enters denominators. "unknown": there is no information, the cell is left out of sums and denominators (alias "nodata").

weights#

Cell values used to weight another quantity. In exposure, a person’s own raster values weight an environment layer.

exposure#

The weighted mean of an environment layer over an entity’s raster.

composition#

The share of each class of a categorical raster (for example land use), possibly weighted.

coverage#

In zonal_composition(), the share of a polygon’s area covered by valid raster cells.

surface#

A raster computed from many entities’ rasters: for example the mean over a group, on a common grid.

stack#

An xarray array with one layer per entity.

grid / lattice / origin#

The regular pattern of cells (CRS, cell size and the position of the upper-left corner). Rasters can be combined without resampling only if they sit on the same lattice.

resampling, reprojection, snapping#

The three ways to make rasters compatible: change the cell size, change the CRS, or shift a small sub-cell offset to the nearest cell. Always explicit.

UDOI#

Utilization distribution overlap index. Two rasters are normalised to unit mass; the index is the overlap area times the integral of the product of the two. Identical uniform ranges give 1; concentrated overlapping ranges can exceed 1.

Jaccard overlap#

Cells above a threshold in both rasters divided by cells above the threshold in either.

lazy#

Pixels are read only when an operation needs them, and only for the rows involved.

backend#

The component that reads a raster’s metadata and pixels (GeoTIFF files, computed rasters, or your own).

derived raster / generator#

A raster defined by a function and parameters, computed when read.

PPGIS#

Public participation GIS: map-based surveys where respondents mark places.

IREM#

Individualized residential exposure model (Hasanzadeh, Laatikainen and Kyttä 2018): a per-person raster of exposure built from the home, daily errand places, visit frequency, travel mode and routes. The example data use an IREM-style model, not the original software.

home range#

The area a person’s everyday places span; in IREM the convex hull of buffers around home and places.
