One value per entity: the column accessor#

Calling a method on a raster column (gdf["col"].raster.…, or .rst.…) works on every row and returns a Series with the table’s index, so the result can be assigned to a new column. Nothing here combines different entities’ rasters, so no outside= choice is needed.

import tempfile
import numpy as np, pandas as pd, geopandas as gpd
import entityraster as er
from entityraster import synth

data = synth.make_dataset(tempfile.mkdtemp(), n=100, seed=3)
gdf = data.people                                   # a GeoDataFrame: home point + an `activity_space` raster column
gdf[["age", "gender", "activity_space"]].head(3)
age gender activity_space
0 18 female <Raster 40×41 @50m>
1 63 female <Raster 75×55 @50m>
2 67 male <Raster 50×47 @50m>

Metadata: free#

Reading metadata never touches the pixels (it was cached when the table was built, and is saved in GeoParquet):

Statistics#

er.READS.reset()
gdf["mean_value"] = gdf["activity_space"].raster.mean()
gdf["area_km2"] = gdf["activity_space"].raster.area(0.5, relative=True) / 1e6
print("rasters read:", er.READS.total, "of", len(gdf))
gdf[["mean_value", "area_km2"]].describe().round(2)

Available: sum, mean, max, area(threshold, relative=False), centroid() (a GeoSeries), and reduce(func) for anything else:

gdf["activity_space"].raster.reduce(lambda a: float(a.std())).head(3)       # a function that gets one masked array

0    0.064556
1    0.049453
2    0.047398
dtype: float64

Only the rows you ask for are read, which is why filtering first is cheap:

er.READS.reset()
old = gdf[gdf["age"] > 70]
old["activity_space"].raster.mean()
print(f"{er.READS.total} rasters read for {len(old)} selected people")

20 rasters read for 20 selected people

A raster’s extent as a geometry#

extent(kind) computes a polygon for every raster, to use as a second geometry column:

gdf["bbox"] = gdf["activity_space"].raster.extent("bounds")          # bounding box, no pixel reads
gdf["home_range"] = gdf["activity_space"].raster.extent("hull")      # convex hull of the valid cells
home_ranges = gdf.set_geometry("home_range")
(home_ranges.geometry.area / 1e6).describe().round(2)

count    100.00
mean       6.21
std        4.25
min        0.88
25%        3.22
50%        5.00
75%        8.18
max       25.24
dtype: float64

extent("valid") is the exact outline of the cells that have a value; add threshold=0.5, relative=True for only the high-value cells.

zones = data.neighbourhoods.set_index("neighbourhood")
share = gdf["activity_space"].iloc[:3].raster.zonal(zones, "share")     # share of each person's total value inside each zone

zonal(zones, stat) accepts "sum", "mean", "max" and "share". For one shared categorical raster against many polygons use entityraster.zonal_composition() (Weighted analysis and land use).

Derived rasters, lazily#

map(func) makes a new raster column whose pixels are func(source pixels), computed only when read:

er.READS.reset()
doubled = gdf["activity_space"].raster.map(lambda a: a * 2)
print("reads after map:", er.READS.total)
print(round(doubled.raster.mean().iloc[0] / gdf["mean_value"].iloc[0], 3))   # exactly 2

reads after map: 0
2.0
