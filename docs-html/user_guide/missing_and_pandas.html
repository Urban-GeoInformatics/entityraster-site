Missing rasters and everyday pandas#

A missing raster is a missing value#

import tempfile
import numpy as np, pandas as pd, geopandas as gpd
import entityraster as er
from entityraster import synth

data = synth.make_dataset(tempfile.mkdtemp(), n=60, seed=2)
gdf = data.people[["age", "income", "gender", "neighbourhood", "activity_space", "geometry"]].copy()
gdf.loc[5, "activity_space"] = None                  # this person has no raster

m = gdf.loc[5, "activity_space"]
print(repr(m), "| isna:", pd.isna(m), "| mean:", m.mean())

<missing raster> | isna: True | mean: nan

gdf["activity_space"].isna().sum(), gdf["activity_space"].raster.mean().isna().sum(), len(gdf.dropna(subset=["activity_space"]))

(np.int64(1), np.int64(1), 59)

Statistics of a missing raster are NaN, isna() and dropna() work, and the cross-entity operations skip it (it does not count as an entity).

Operations that keep rasters with their rows#

The raster column is a normal column, so all the usual operations carry it along:

older = gdf[gdf["age"] > 50]                                         # filter
srt = gdf.sort_values("age")                                         # sort
both = pd.concat([gdf.iloc[:3], gdf.iloc[-3:]])                      # concatenate
lookup = pd.DataFrame({"neighbourhood": [0, 1, 2], "label": list("abc")})
merged = gdf.merge(lookup, on="neighbourhood", how="left")           # merge with another table
projected = gdf.to_crs(4326)                                         # GeoPandas geometry operations leave the rasters alone
joined = gpd.sjoin(gdf, data.neighbourhoods[["neighbourhood", "geometry"]].rename(columns={"neighbourhood": "nb"}))
[er.is_georasterframe(x) for x in (older, srt, both, merged, projected, joined)]

[True, True, True, True, True, True]

Recognising a GeoRasterFrame#

type(gdf) is just GeoDataFrame; use the helpers:

er.is_georasterframe(gdf), er.is_georasterframe(gdf, geometry=True), gdf.rst.raster_columns, er.is_georasterframe(gdf[["age"]])

(True, True, ['activity_space'], False)

Things pandas does that surprise people#

Whole-table statistics fail with a raster column present, exactly as they do with a geometry column or a text column, because pandas cannot average rasters:

try:
    gdf.groupby("gender", observed=True).mean()
except TypeError as e:
    print("TypeError:", str(e)[:90])

TypeError: agg function failed [how->mean,dtype->raster]

Restrict to numbers, or select the columns you want:

gdf.groupby("gender", observed=True).mean(numeric_only=True).round(1)
age income neighbourhood
gender
female 49.5 49830.9 9.7
male 49.3 42544.2 8.8
other 52.5 25910.2 10.0

To average the rasters themselves, use the accessor: gdf["activity_space"].raster.mean() per person, or a group surface (Combining entities: surfaces, stacks and overlap).

.loc[200, col] returns a single raster only if the index is unique. With duplicate ids it returns a Series, and calling .mean() on it raises an error that points to .rst.

dup = pd.concat([gdf, gdf.iloc[[0]]])
try:
    dup.loc[dup.index[0], "activity_space"].mean()
except TypeError as e:
    print("TypeError:", e)

TypeError: reduction 'mean' is not supported for raster references; use .rst reductions

.raster versus .rst. On a column they are the same. A table only has .rst, because .raster would collide with a column named raster (the default name that embed creates).
