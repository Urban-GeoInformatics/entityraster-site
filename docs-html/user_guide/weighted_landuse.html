Weighted analysis and land use#

Two related jobs:

  1. How much of some environment does each entity’s raster expose them to? The entity’s raster values act as weights: cells they use more count more.

  2. What is the composition of a land-use (categorical) raster inside each entity’s raster, or inside each polygon of another table?

import tempfile, pathlib
import numpy as np, pandas as pd, geopandas as gpd, rasterio
import entityraster as er
from entityraster import synth

data = synth.make_dataset(tempfile.mkdtemp(), n=150, seed=7)
gdf = data.people

# A continuous environment layer (greenness 0..1, with gaps = "unknown") and, derived from it, a land-use map with 3 classes.
with rasterio.open(data.out_dir / "env_green.tif") as src:
    green = src.read(1, masked=True); profile = src.profile
classes = np.where(green.mask, -9999, np.digitize(green.filled(0), [0.33, 0.66]) + 1).astype("float32")      # 1, 2, 3
lu_path = data.out_dir / "landuse.tif"
with rasterio.open(lu_path, "w", **profile) as dst:
    dst.write(classes, 1)
greenness, landuse = data.env_green, er.RasterRef(str(lu_path))
landuse.shape, np.unique(classes[classes > 0])

((600, 600), array([1., 2., 3.], dtype=float32))

exposure is the weighted mean of the layer: each cell’s value is multiplied by the entity’s own raster value in that cell, summed, and divided by the sum of the weights. Choose the weights with weighting=:

weighting

weights

typical use

"density" (default)

the entity’s raster values

exposure-weighted (a person’s use of each cell)

"binary"

1 where the raster value exceeds threshold, else 0

an unweighted home range

"none"

1 on every valid cell

the plain mean over the raster’s extent

 
w = pd.DataFrame({
    "density-weighted": gdf["activity_space"].rst.exposure(greenness, outside="unknown"),
    "home range (binary)": gdf["activity_space"].rst.exposure(greenness, outside="unknown", weighting="binary", threshold=0.0),
})

outside= here is about the environment layer: if the layer has gaps (or does not cover an entity’s whole raster), "unknown" drops those cells from numerator and denominator, "zero" counts them as 0. If the whole raster lies in a gap, the result is NaN.

Share of chosen land-use classes#

With classes=[...] the layer is read as categorical and the result is the weighted share of the weight that falls in those classes:

shares.head(4).round(2)

0 0.94 0.06 0.00
1 0.87 0.13 0.00

Each row is one entity’s weighted class shares. With outside="unknown" they sum to 1 over what the land-use map observes; with "zero" the unobserved part stays in the denominator and the shares sum to the observed fraction.

zero_shares = gdf["activity_space"].rst.composition(landuse, outside="zero")
pd.DataFrame({"unknown": shares.sum(axis=1), "zero": zero_shares.sum(axis=1)}).describe().round(3).loc[["min", "mean", "max"]]
unknown zero
min 1.0 0.010
mean 1.0 0.956
max 1.0 1.000

One land-use raster, many polygons#

For a shared categorical raster against polygons (neighbourhoods, districts) use entityraster.zonal_composition(). It returns the class shares per polygon and a coverage column: the share of the polygon covered by valid cells.

zones = data.neighbourhoods.set_index("neighbourhood")
comp = er.zonal_composition(landuse, zones)
comp.head(4).round(2)

Weight the cells with another raster (for example population) using weights=; it is aligned to the land-use grid with the usual rules (Alignment: rasters that do not line up):

pollution = er.RasterRef(str(data.out_dir / "env_pollution.tif"))          # stand-in for a population raster
er.zonal_composition(landuse, zones, weights=pollution).head(3).round(2)

neighbourhood
0 0.53 0.43 0.04 0.93
1 0.31 0.68 0.01 1.00

Note

Shares count the cells whose centre lies in the polygon. For coarse cells and small polygons, tools that use exact partial-cell coverage (exactextract) are more precise.
