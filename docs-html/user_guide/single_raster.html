One entity’s raster#

gdf.loc[uid, "column"] returns that entity’s raster as a RasterRef: the reference to the file plus its metadata. It has the same statistics as the column accessor, but returns single numbers.

import tempfile
import pandas as pd, matplotlib.pyplot as plt
import entityraster as er
from entityraster import synth

data = synth.make_dataset(tempfile.mkdtemp(), n=100, seed=3)
survey = pd.DataFrame(data.people.drop(columns=["geometry", "activity_space", "path"])).rename(columns={"person_id": "uid"})
gdf = er.embed(survey, data.out_dir / "rasters", on="uid", pattern="p{uid:05d}.tif", column="activity_space", index="uid")

p = gdf.loc[20, "activity_space"]
p

RasterRef(href='/var/folders/d5/hzj_s3dn4gj_pdr3911r_qc00000gn/T/tmpsqg0hfdx/rasters/p00020.tif', band=1, backend='geotiff', crs='EPSG:3067', transform=(50.0, 0.0, 393650.0, 0.0, -50.0, 6664400.0), width=54, height=52, dtype='float32', nodata=-9999.0, params=None)

area(threshold) is the area (in the CRS’s units squared, here m²) of cells above threshold; with relative=True the threshold is a fraction of the raster’s own maximum, which is how a “high-exposure area” is defined:

p.area(0.5, relative=True) / 1e6, p.centroid()

(4.27, <POINT (394792.879 6662955.237)>)

Nodata cells#

Many rasters have cells with no value (for example outside a modelled home range). By default statistics ignore them, because for a single raster those cells are simply not part of it. Count them as zero if you really want that:

valid = p.values()                                      # a masked NumPy array
print("valid cells:", int(valid.count()), "of", valid.size)
print("mean ignoring nodata  :", round(p.mean(), 3))
print("mean counting them as 0:", round(p.mean(nodata="zero"), 3))

valid cells: 1708 of 2808
mean ignoring nodata  : 0.626
mean counting them as 0: 0.381

Note

Why ignore is the default here but outside= is mandatory elsewhere: the mean of one raster counted over a bounding box would depend on how big that arbitrary box happens to be. Across several entities, the meaning of an empty cell is a genuine modelling choice (Concepts).

A missing raster is a missing value#

If a row has no raster, gdf.loc[uid, column] is er.MISSING: a NaN for which pd.isna is true. Statistics return NaN, so a loop over rows needs no special case.

g = gdf.copy()
g.loc[20, "activity_space"] = None
m = g.loc[20, "activity_space"]
print(repr(m), pd.isna(m), m.mean())

<missing raster> True nan
