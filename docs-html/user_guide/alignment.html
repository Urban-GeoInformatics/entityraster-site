Alignment: rasters that do not line up#

To combine rasters they must share a coordinate system (CRS), a cell size and an origin (the cells’ grid positions). entityraster checks this and, if anything differs, stops and names the rows and the difference instead of silently pasting arrays together. You then opt in to the fix you want.

the rasters differ in

you get an error unless you pass

what happens

CRS

reproject=True

the raster is warped to the reference CRS

cell size

resampling="nearest" (or "bilinear", "average", …)

the raster is resampled to the reference cell size

origin (sub-cell offset)

snap=True or resampling=...

shifted to the nearest cell, or resampled

The reference is the first raster with a value (or the grid you give, see below).

import tempfile
import numpy as np, pandas as pd
import entityraster as er
from entityraster import synth

# 80 people, of which one has a 100 m raster, one is in EPSG:4326 and one is shifted by a fraction of a cell
# edge_cases plants the misaligned rasters so the checks below have something to find
data = synth.make_dataset(tempfile.mkdtemp(), n=80, seed=3, edge_cases=synth.EdgeCases(res100=1, epsg4326=1, offgrid=1))
col = data.people["activity_space"]            # the raster column, as a Series
data.edge_ids                                  # which rows got which edge case

{'res100': [59],
 'epsg4326': [44],
 'offgrid': [17],
 'missing': [],
 'all_nodata': []}

Find the problem before it bites#

check = col.rst.compatible()                 # one row per raster: does it match the first one's grid?
check[~check["compatible"]]                   # show only the rasters that do not
compatible reason
17 False origin is off the lattice by (17, 23) CRS units
44 False CRS EPSG:4326 differs from EPSG:3067
59 False resolution 100x100 differs from 50x50

What the error looks like#

try:
    # no fix requested, so the mismatch raises an error that names the rows and the difference
    col.rst.surface("mean", outside="zero")
except er.AlignmentError as e:
    print(e)

3 of 80 rasters are incompatible with the reference lattice (CRS=EPSG:3067, res=50x50):
  row 17: origin is off the lattice by (17, 23) CRS units (pass snap=True to shift it to the nearest cell, or resampling=... to resample it)
  row 44: CRS EPSG:4326 differs from EPSG:3067 (pass reproject=True to warp it)
  row 59: resolution 100x100 differs from 50x50 (pass resampling='nearest'|'bilinear'|... to resample it)

Choose the fix#

# opt in to both fixes: resample cell sizes bilinearly and reproject the EPSG:4326 raster
fixed = col.rst.surface("mean", outside="zero", resampling="bilinear", reproject=True)
fixed.shape

(563, 560)

If only the origin is off, snap=True is cheaper than resampling (it just shifts to the nearest cell). Compatible rasters are never resampled:

# drop the rows flagged incompatible above, leaving rasters that already share a grid
ok = col.drop(col.index[~check["compatible"]])
ok.rst.surface("mean", outside="zero").shape                         # no options needed: all rasters are compatible

(563, 560)

Choose the grid yourself#

By default the result is on the union of all extents. Other choices:

# the smallest grid that covers every raster's extent (this is also the default)
union = er.Grid.union(list(ok.array))
print("union of all rasters:", union.shape, "| cell size:", union.res)

union of all rasters: (563, 560) | cell size: (50.0, 50.0)

The intersection is the area every raster covers. For rasters that do not overlap it is empty, and you get an error:

try:
    # the first 5 rasters share no common area, so there is no intersection and an error is raised
    er.Grid.intersection(list(ok.array[:5]))
except ValueError as e:
    print("ValueError:", e)

ValueError: the rasters have an empty intersection

For two people whose rasters do overlap (found with overlap) it is the shared area:

# take the pair with the highest Jaccard overlap (the last row after sorting)
pair = ok.rst.overlap("jaccard", outside="zero").sort_values("value").iloc[-1]
two = ok.loc[[pair.i, pair.j]]                  # the two people in that pair
print("shared area grid:", er.Grid.intersection(list(two.array)).shape)
two.rst.stack(grid="intersection", outside="zero").shape         # both layers cropped to the area both cover

shared area grid: (51, 55)

(2, 51, 55)

Or pass a grid you built, for example to match another map:

# a custom grid: a 5 km x 5 km box starting at the union's lower-left corner, with 50 m cells
mine = er.Grid.from_bounds(union.crs, (union.bounds[0], union.bounds[1], union.bounds[0] + 5000, union.bounds[1] + 5000), 50.0)
ok.rst.surface("mean", outside="unknown", grid=mine).shape

(100, 100)

Alignment is also checked for environment layers#

exposure, composition and zonal_composition align the environment (or weight) layer to each raster the same way; pass resampling= etc. there too.

try:
    # point a reference at one of the 100 m rasters and use it as the environment layer
    coarse = er.RasterRef(str(data.out_dir / "rasters" / f"p{data.edge_ids['res100'][0]:05d}.tif"))     # a 100 m raster used as the layer
    col.iloc[:3].rst.exposure(coarse, outside="unknown")      # layer and rasters differ in cell size, so this raises
except er.AlignmentError as e:
    print(str(e).splitlines()[0])                              # just the first line of the message
