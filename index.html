entityraster

Raster-valued attributes for GeoPandas. One raster per row, handled like any other column.

  • Documentation
  • GitHub
  • PyPI

Keep a person's activity space, a site's suitability surface or a parcel's land-cover map in a table, next to the entity's other attributes. Filter, group, join and save it the way you already do with tables. We call such a table a GeoRasterFrame.

import entityraster as er

gdf = er.embed(people, "rasters/", on="uid", pattern="p{uid:05d}.tif",
               column="activity_space", index="uid")

gdf.loc[200, "activity_space"].mean()                                  # one person's raster
gdf["area_km2"] = gdf["activity_space"].raster.area(0.5, relative=True) / 1e6
old = gdf[gdf["age"] > 60]                                             # rasters follow the filter
old.rst.surface("activity_space", by="gender", outside="unknown")      # a mean surface per group

What it does

  • Attach rasters by key (embed): catalogue, file-name pattern, folder, path column. Unmatched rows and unused files are reported, never silently dropped.
  • Lazy. The table holds references and metadata; pixels are read only for the rows an operation needs.
  • Rasters with different extents are aligned with strict, explained rules (reproject=, resampling=, snap= are opt-in).
  • Zero or unknown? Operations across entities make you state what a cell outside a raster means.
  • Weighted analysis and land use: exposure weighted by each entity's raster, class shares per entity and per polygon.
  • Plain pandas: filter, groupby, merge, sjoin and GeoParquet keep working; export surfaces as GeoTIFF for QGIS and ArcGIS.
