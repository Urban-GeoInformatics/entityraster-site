# entityraster-site

Landing page for [entityraster](https://github.com/Urban-GeoInformatics/entityraster), served with GitHub Pages
(Settings → Pages → deploy from branch `main`, folder `/ (root)`).

Static HTML, no build step: edit `index.html` and push. The full documentation lives on Read the Docs and is built from the
`docs/` folder of the library repository.
